# 🌿 EcoSpark

EcoSpark is an innovative sustainability platform that gamifies eco-friendly living through AI-powered challenges, carbon footprint tracking, and community engagement. Unlike traditional trackers, EcoSpark combines behavioral science with generative AI to deliver personalized sustainability recommendations.

## ✨ Key Features

### 🌱 Smart Sustainability Tracking
- **AI-Powered Insights**: Gemini AI analyzes your habits to provide tailored eco-tips
- **Dynamic Scoring**: Earn points for sustainable actions (10 pts/day max)
- **Visual Dashboard**: Interactive charts show your environmental impact over time

### 🏆 Gamified Challenges
```python
def generate_challenge(category):
    challenges = {
        "energy": "Turn off lights for 2 extra hours today",
        "waste": "Avoid single-use plastics for 24 hours",
        "transport": "Try carpooling or public transit today"
    }
    return challenges.get(category, "Share your eco-tip with a friend!")
```

### 🔥 Unique Offerings
- **AI-Powered Scratch Cards**: Reveal rewards through interactive scratch-offs
- **Community Challenges**: Compete in team sustainability missions
- **Skill-Based Recommendations**: Learns your capabilities to suggest achievable goals

## 🛠️ Technical Stack
- **Frontend**: Next.js, Tailwind CSS, Framer Motion
- **Backend**: Flask, SQLite
- **AI**: Google Gemini, Custom recommendation engine
- **OCR**: Tesseract for processing sustainability reports

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   npm install
   ```

2. **Set up environment**:
   ```bash
   cp .env.example .env
   # Add your Google Gemini API key
   ```

3. **Run development servers**:
   ```bash
   flask run --port 5000
   npm run dev
   ```
